# Hatch v0.3.0 — Public preview / 公开预览版

App Launcher is now **Hatch**, with a new paper-inspired icon and consistent
branding across the application, installer, and repository.

## Changes

- New Hatch name and icon on the application window and native bundles.
- Repository renamed to `piercezzs/hatch`; source moved to `apps/hatch`.
- Search debounce and IME composition handling improved since v0.2.0.
- Existing search, grouping, pinned apps, recent activity, bilingual settings,
  and local-only storage behavior are retained.

## Downloads and installation limits

- Apple Silicon Mac: `Hatch_0.3.0_aarch64.dmg`.
- Intel Mac: `Hatch_0.3.0_x64.dmg`.
- Windows x64: `Hatch_0.3.0_x64-setup.exe` — clean installations only.
- Verify downloads against the attached `SHA256SUMS.txt`.

On macOS, quit App Launcher before opening Hatch. Drag Hatch.app to Applications;
its new filename does not overwrite App Launcher.app. Do not run both versions
against their shared data directory at the same time.

The Windows installer does not support or guarantee an upgrade from an existing
App Launcher installation. Existing Windows users should remain on the previous
version until the migration path is verified. The stable application identifier
preserves the data location; it does not prove installer upgrade compatibility.

macOS bundles are ad-hoc signed and **not notarized**. Windows installers are
**unsigned**. Do not disable system security globally. Full Windows and physical
Intel Mac runtime acceptance remain pending; CI build/test success is not that
acceptance. In-app automatic updates are not implemented.
