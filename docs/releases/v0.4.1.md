# Hatch v0.4.1 — In-app updates / 应用内更新

Hatch adds signed whole-package updates from one stable release feed. This release
must be installed manually by users of v0.3.0 and earlier.

## Changes

- Embed the Windows Common Controls manifest in application and unit-test binaries
  so the native test suite can start on Windows.

- Check for updates in Settings, with an optional automatic check once per day.
- Download progress, update notes, retry after failures, and explicit installation
  confirmation. Automatic checks never automatically download or install.
- Verify updater signatures before installation. Reject older versions and
  prereleases; preserve the application identifier and existing user-data formats.
- Finish or close application/group edits before installing. Coordinate pending
  storage writes and use atomic JSON replacement.
- On macOS, retain a recovery copy of the application during installation and
  report its location if automatic recovery fails.

## Downloads

- Apple Silicon Mac: `Hatch_0.4.1_aarch64.dmg`.
- Intel Mac: `Hatch_0.4.1_x64.dmg`.
- Windows x64: `Hatch_0.4.1_x64-setup.exe`.
- `*.app.tar.gz` archives and `.sig` files are updater assets, not the usual
  first-installation downloads. Verify asset hashes using `SHA256SUMS`.

## Installation and acceptance boundaries

The first updater-enabled Hatch installation is manual. Existing v0.3.0 binaries
cannot discover or install this new capability automatically. Quit Hatch before
replacing it, and keep a backup of user-owned data.

Legacy App Launcher-to-Hatch migration remains unsupported on Windows. Keep using
the old installation until that migration path is verified. On macOS, Hatch.app
does not remove App Launcher.app; never run both against the shared data directory.

macOS packages are ad-hoc signed and not notarized. Windows installers are not
publisher-signed. Updater signatures authenticate update payloads and do not provide
OS publisher identity. Do not disable system security globally.

Automated tests and CI builds do not establish physical-device acceptance. Full
cross-version update, installation/restart and data-preservation acceptance on
macOS ARM64, macOS Intel and Windows x64 remains required before this draft is
published. This is whole-package updating; frontend code hot updates are not included.

## 中文说明

- 设置中新增检查更新、每日自动检查、下载进度、失败重试和安装确认。
- 仅接收正式版本；下载完成并通过签名验证后，仍需用户确认安装。
- 安装前需保存或关闭编辑；保留应用标识和现有数据格式。
- v0.3.0 及更早版本用户需手动安装首次支持更新的版本。
- Windows 旧 App Launcher 迁移尚不支持；macOS 不会自动删除旧 App Launcher.app。
- macOS 尚未公证，Windows 尚未进行发布者签名；更新签名不等于操作系统发布者认证。
- 此草稿发布前仍需完成三平台真实安装、跨版本升级、重启及数据保留验收。
