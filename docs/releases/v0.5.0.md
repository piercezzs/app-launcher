# Hatch v0.5.0 — Paper-minimal preview / 纸纹极简预览版

Hatch now starts in paper-minimal mode when no interface preference has been saved.
This public preview is downloaded manually and does not advance the stable update
feed. An explicitly saved Standard or Minimal choice is preserved.

## Changes

- A warm paper background, one application grid, search, All / Pinned / Recent
  tabs, and an independent group filter. The compact layout adapts to narrow windows.
- Open details and management actions when needed. More provides settings,
  grouping, sorting, rescanning, adding entries and a return to Standard mode.
- Preserve local apps, groups, pins, history and search behavior across modes.
  Missing paths open recovery details instead of launching a fallback.
- Correct group-button alignment, menu action dispatch and dialog focus restoration.
- Replace the old README screenshots with actual v0.5.0 macOS views in both languages.
- Include the updater work since the v0.3.0 public preview: signed payloads,
  download progress, retry and explicit install confirmation. Automatic checks do
  not automatically download or install. Unavailable sources report a failed check,
  not a false up-to-date result.
- Include expanded, bounded Windows application discovery. Close the temporary
  script's write handle before PowerShell reads it, and correct the Windows
  loopback test server's socket mode.

## Downloads

- Apple Silicon Mac: `Hatch_0.5.0_aarch64.dmg`.
- Intel Mac: `Hatch_0.5.0_x64.dmg`.
- Windows x64: `Hatch_0.5.0_x64-setup.exe`.
- Check file hashes against `SHA256SUMS`. Updater archives (`*.app.tar.gz`) and
  `.sig` files are separate from normal first-installation downloads.

## Acceptance and installation boundaries

macOS Apple Silicon has native runtime checks for default mode, switching,
search, app management, missing paths and narrow layout. Automated frontend,
Rust and release-verifier tests are required, as are all three packaging jobs.
CI builds do not establish physical Windows or Intel Mac acceptance. Full
cross-version installation, restart and data-preservation acceptance, plus some
visual failure/busy states, remain pending. This is why the release is a preview.

The stable update feed excludes this prerelease. v0.3.0 and earlier users must
install it manually. Settings may report that the update source is unavailable
while no stable feed has been published; launching local apps is unaffected.

Quit Hatch before replacing its app bundle. Keep backups of user-owned data.
Legacy App Launcher-to-Hatch migration remains unverified on Windows; this preview
is limited to clean Windows installations. On macOS, Hatch.app does not remove
App Launcher.app: do not run both against their shared data directory.

macOS packages are ad-hoc signed and not notarized; Windows installers are not
publisher-signed. Updater signatures authenticate payloads, not OS publisher
identity. Do not disable system security globally.
